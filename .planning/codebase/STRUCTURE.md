## Directory Purposes

**TazeKalsin.API/Controllers/:**
- Purpose: HTTP endpoint definitions; one file per controller
- Contains: Classes inheriting ControllerBase, decorated with [ApiController] and [Route]
- Key files: `TazeKalsin.API/Controllers/AuthController.cs`

**TazeKalsin.API/Models/:**
- Purpose: All request DTOs, response DTOs, and data transfer objects
- Contains: Plain C# classes with auto-properties; no annotations or validation attributes
- Key files: `TazeKalsin.API/Models/RegisterRequest.cs`, `TazeKalsin.API/Models/AuthResponse.cs`, `TazeKalsin.API/Models/TuketiciDto.cs`

**TazeKalsin.API/Services/:**
- Purpose: Business logic and data access; one interface + one implementation per domain area
- Contains: Interface file (IXxxService.cs) paired with implementation (XxxService.cs)
- Key files: `TazeKalsin.API/Services/IAuthService.cs`, `TazeKalsin.API/Services/AuthService.cs`

**TazeKalsin.Tests/:**
- Purpose: xUnit unit tests; mirrors the API project structure
- Contains: Test classes named after the class under test + Tests suffix
- Key files: `TazeKalsin.Tests/AuthControllerTests.cs`

## Key File Locations

**Entry Points:**
- `TazeKalsin.API/Program.cs`: Application bootstrap, DI registrations, middleware pipeline

**Configuration:**
- `TazeKalsin.API/appsettings.json`: Connection string (TazeKalsinDB), JWT settings (Secret, Issuer, Audience, ExpiryDays), log levels
- `TazeKalsin.API/appsettings.Development.json`: Development-specific overrides

**Core Logic:**
- `TazeKalsin.API/Services/AuthService.cs`: All auth business logic -- BCrypt hashing, SQL queries, JWT generation
- `TazeKalsin.API/Controllers/AuthController.cs`: Input validation guards, delegates to IAuthService

**Schema:**
- `tazekalsin.sql`: SQL Server DDL for the Tuketici table

**API Spec:**
- `tazekalsin-api.json`: OpenAPI 3.0.1 spec with all endpoint schemas

**Testing:**
- `TazeKalsin.Tests/AuthControllerTests.cs`: All 6 controller unit tests

## Naming Conventions

**Files:**
- Controllers: PascalCase + Controller suffix -- e.g., AuthController.cs
- Service interfaces: I prefix + PascalCase + Service suffix -- e.g., IAuthService.cs
- Service implementations: PascalCase + Service suffix -- e.g., AuthService.cs
- Request DTOs: PascalCase + Request suffix -- e.g., RegisterRequest.cs, LoginRequest.cs
- Response DTOs: PascalCase + Response or Dto suffix -- e.g., AuthResponse.cs, TuketiciDto.cs
- Test files: PascalCase + tested class name + Tests suffix -- e.g., AuthControllerTests.cs

**Directories:**
- PascalCase, plural for collections: Controllers/, Models/, Services/
- Singular for project folders: TazeKalsin.API/, TazeKalsin.Tests/

**C# identifiers:**
- Public properties: PascalCase -- e.g., Ad_Soyad, Tuketici_ID (snake_case hybrid for DB column alignment)
- Private fields: underscore + camelCase -- e.g., _authService, _connectionString
- Methods: PascalCase in English for infrastructure, Turkish for domain methods -- e.g., KayitOl, GirisYap, EmailMevcutMu, TokenUret

## Where to Add New Code

**New domain feature (e.g., Isletme/business auth):**
- Service interface: `TazeKalsin.API/Services/IIsletmeService.cs`
- Service implementation: `TazeKalsin.API/Services/IsletmeService.cs`
- Controller: `TazeKalsin.API/Controllers/IsletmeController.cs`
- Request/response DTOs: `TazeKalsin.API/Models/IsletmeXxxRequest.cs` / `TazeKalsin.API/Models/IsletmeDto.cs`
- Register in DI: `TazeKalsin.API/Program.cs` -- add builder.Services.AddScoped<IIsletmeService, IsletmeService>()
- Tests: `TazeKalsin.Tests/IsletmeControllerTests.cs`

**New endpoint on existing controller:**
- Add method to `TazeKalsin.API/Controllers/AuthController.cs`
- Add method signature to `TazeKalsin.API/Services/IAuthService.cs`
- Implement in `TazeKalsin.API/Services/AuthService.cs`
- Add test case to `TazeKalsin.Tests/AuthControllerTests.cs`

**New DTO:**
- Add to `TazeKalsin.API/Models/` -- one class per file, filename matches class name

**Shared utilities / helpers:**
- No Helpers/ directory exists yet; create `TazeKalsin.API/Helpers/` for shared static utilities
- Middleware: create `TazeKalsin.API/Middleware/` and register in `TazeKalsin.API/Program.cs`
